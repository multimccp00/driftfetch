# Project rules

## Commits and pull requests
- No co-author trailers, "generated with" lines or any other tool attribution in commit messages or PR descriptions.
- Commits are authored by the repo owner only.

## Content
- Nothing NSFW in the repo: no adult or booru site names, code, examples or comments, in code, docs or the website.
- Extensions for such sites stay local as built `.current-extension` files in `app/local-extensions/`, which is gitignored. Never commit them.
- Use neutral examples (for instance "landscapes") in docs and pages.
