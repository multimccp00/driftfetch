Installer or portable?

Installer Recommended

Adds DriftFetch to the Start menu, can start with Windows and appears in Settings › Apps for a clean uninstall.

Portable

Unzip it anywhere, even a USB stick, and run DriftFetch.exe. Settings stay next to the app and nothing is written to Windows. To remove it, delete the folder.

Installing takes a minute

  1. 01

    Run the installer

    Open the installer. It installs for your user only, so it doesn’t need admin rights. Using the portable version? Unzip it and run DriftFetch.exe instead.

  2. 02

    If Windows warns you

    New apps can trigger “Windows protected your PC”. Click “More info”, then “Run anyway”.

  3. 03

    Look in your tray

    DriftFetch starts next to the clock. Copy a video link and it takes it from there.

What you need

Windows 10 or 11, 64-bit

Fully updated versions are recommended. Windows on ARM isn’t supported yet.

Space for the app and its tools

FFmpeg, yt-dlp, gallery-dl and Deno are bundled, so there’s nothing else to install.

An internet connection

Only to reach the sites you download from, and GitHub for engine updates.

Is DriftFetch safe?

It’s open source, so anyone can read the code, and each release lists its SHA-256 checksum so you can confirm the file wasn’t changed.

Why does Windows say “Windows protected your PC”?

Windows shows this for new apps that haven’t been downloaded many times yet. Click “More info”, then “Run anyway”. The checksum on this page lets you confirm the file is genuine first.

How do I uninstall it?

Installer: open Windows Settings › Apps, find DriftFetch and choose Uninstall. Portable: delete its folder. Either way, your downloaded files stay where they are.
