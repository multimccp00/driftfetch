# DriftFetch compatibility matrix

This is the list of sources DriftFetch has actually checked. It is deliberately not a claim that every link from a listed site will work. Sites change, availability varies by region and account, and an engine update can change results.

Run `npm run test:sources` to repeat the public metadata checks. The command creates a dated JSON result under `test-results` and never downloads media. Packaged smoke checks separately verify direct media, redirects, embedded media, DASH merging, image-gallery selection and recovery using local permitted fixtures. Encrypted sessions are checked in the source-run smoke suite, because the packaged run cannot stub the file dialog.

For a source-specific check, `node scripts/check-links.mjs --browser chrome:Default <link>` reads the selected Chrome session through the engine without exporting it. It records only the source domain and non-sensitive extraction result, and it never downloads media.

## How to read the table

- **Metadata and formats available** means DriftFetch can identify the item and offer the formats reported at the time of the check. It is not a completed full-file download test.
- **Verified** entries were downloaded with DriftFetch’s packaged app using permitted local media fixtures; they demonstrate the app workflow, not a particular external host’s continuing availability.
- **Needs attention** stays in the table to show the real condition and the next action, such as importing an account session or testing a permitted link.

The engine has a much wider extractor list, but its maintainers state that listed sites can still fail as sites change. DriftFetch only promotes an item in this table after its own check. [yt-dlp supported-site notes](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
