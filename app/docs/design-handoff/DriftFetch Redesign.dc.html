1DriftFetch redesign — design system, Downloads, picker, details, settings
Direction
Calm navy-black surfaces with a hint of the icon’s blue. Electric blue is the one action colour (primary buttons, selection, links); cyan is reserved for live motion — progress and focus. Status colours carry meaning only.
What changed
Layout matches the current app: brand block and workspace nav, listening strip, stat cards, list card with tabs, filters and footer. The change is the palette (from the new icon), plainer copy, real thumbnail slots, and rate limits counted as Active instead of Failed.
Build notes
Segoe UI Variable (ships with Windows) + Cascadia Mono (OFL, bundle it) — no web fonts. Lucide icons at 1.75 stroke. Every value below maps to a CSS variable. Artboards 1c–1l are live: click tabs, rows, checkboxes, toggles, settings sections.
